The ``add_integer`` function
=============================

Import the function:

    >>> add_integer = __import__('0-add_integer').add_integer

Add two positive integers:

    >>> add_integer(1, 2)
    3

Add a positive and a negative integer:

    >>> add_integer(100, -2)
    98

Use the default value for b:

    >>> add_integer(2)
    100

Floats are cast to integers before adding:

    >>> add_integer(100.3, -2)
    98

Floats are truncated, not rounded:

    >>> add_integer(1.9, 1.9)
    2

Both a and b can be floats:

    >>> add_integer(3.7, 4.2)
    7

Passing a non-number for a raises a TypeError:

    >>> add_integer(None)
    Traceback (most recent call last):
    TypeError: a must be an integer

Passing a non-number for b raises a TypeError:

    >>> add_integer(4, "School")
    Traceback (most recent call last):
    TypeError: b must be an integer
